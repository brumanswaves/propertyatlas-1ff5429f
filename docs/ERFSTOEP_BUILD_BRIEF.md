# ErfStoep Build Brief

## Product north star

ErfStoep is a map-first AI command center for South African erf research.

## Core product loop

Click erf -> Stoep AI First Read -> StoepSteps -> Strategy Lab calculator -> Stoep Report -> optional evidence/report upload -> improved confidence.

## Brand names

- Site: ErfStoep
- AI: Stoep AI
- Button: Ask Stoep
- Workflow: StoepSteps
- Reports: Stoep Reports
- Saved area: My Erfs

## Critical product rule

Paid reports are optional confidence upgrades. The free/manual workflow must still feel powerful.

## MVP surfaces

- Homepage hero
- Clicked-erf dashboard
- Stoep AI First Read
- StoepSteps
- Strategy Lab
- Stoep Reports
- Report Vault

## Safety rules

- No fake ownership
- No fake valuation
- No fake zoning
- No fake GIS precision
- No scraping unless explicitly approved
- Use confidence labels and evidence status
- Paid reports should improve confidence, not unlock basic usefulness

## Implementation discipline

- Preserve map and parcel identity logic unless explicitly told otherwise
- Preserve market evidence/radar workflow
- Diagnose only when scope is unclear
- Implement only the approved sprint
- Run build and tests before commit
- Commit and push only after tests pass
