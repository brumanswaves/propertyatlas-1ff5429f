# Easy Erf R999 Human Investigation MVP

Status: canonical commercial MVP direction

## Product promise

Easy Erf helps a buyer or investor answer the practical question: **What do I need to know about this property before I make a decision?**

The near-term commercial MVP is a **R999 human-reviewed Easy Erf Property Investigation** supported by the self-serve investigation product. The platform should do as much evidence collection, organization, calculation and drafting as it can. Human review closes the gaps that are not yet reliably automated.

This is deliberately simpler than trying to automate every property-professional workflow before revenue and customer evidence exist.

## Entry experience

The investigation should begin from the selected erf and existing evidence, not from a long questionnaire.

Ask only the smallest amount of information needed to focus the investigation, including:

1. **What are you trying to do with this property?**
2. **What do you most want to know before deciding?**

Easy Erf should then investigate first and ask follow-up questions only where evidence is genuinely missing or ambiguous.

## Customer output

The R999 investigation should produce a useful decision document organized around:

1. **Property Truth** - what the evidence currently establishes about the erf.
2. **Property Potential** - what appears possible, with verified controls and assumptions kept visibly separate.
3. **Deal Killers / Key Risks** - issues that could materially change the decision.
4. **Conflicts** - places where sources or user information disagree.
5. **Unknowns** - material questions that remain unresolved.
6. **Next Steps** - the shortest practical actions to improve confidence or move the deal forward.

The report must show evidence provenance and confidence. It is not a dump of tabs, files or AI prose.

## Guided product rule

The default Easy Erf experience remains one guided investigation:

`real property -> existing evidence -> targeted missing evidence -> interpretation -> calculations -> risks/unknowns -> report -> next action`

The user should not have to understand the internal workspaces to get value.

### Preserve

- Property First Read
- Guided Investigation
- canonical parcel/property identity
- shared evidence/File Vault
- SG and cadastral evidence
- title and paid-report evidence
- zoning and planning confidence
- property checks
- Market Evidence
- Strategy and deterministic calculators
- deterministic Site Potential building-area/build-envelope analysis
- living Easy Erf Report
- Ask Easy Erf when grounded in the property file
- expert workspaces as secondary tools

### Do not make MVP-critical

- AI architectural concept packs
- multiple generated Site Potential design directions
- complex design-generation job infrastructure
- features that add operational complexity without improving the R999 investigation decision

Existing generated concepts may remain stored as historical user assets, but new concept generation is not part of the R999 MVP path.

## Site Potential scope for this MVP

Site Potential should answer a simple due-diligence question:

**Based on the parcel and the planning information we currently have, what approximate area may be available for building, and which inputs are verified versus assumed?**

It is not an architectural design service. It should not require three generated concepts before the user can complete the investigation.

## Automation rule

Automate recurring work after real customer investigations show what is repeatedly slow, expensive or valuable.

Do not build broad automation merely because it is technically possible. Customer evidence determines the next automation priorities.

## Gold-standard acceptance property

Erf 1570 remains the vertical-slice property. The MVP is not accepted merely because code builds or data migrated. A real signed-in user must be able to reopen Erf 1570, use the evidence and guided investigation, understand what is known and unknown, and reach a useful report and next action.

## Commercial learning loop

Each paid investigation should record:

- what the customer wanted to decide
- which facts Easy Erf obtained automatically
- which facts required human research
- which uploads were needed
- which findings changed the decision
- which report sections mattered most
- where the customer still needed a professional
- which recurring manual task should be automated next

The purpose of the R999 offer is both revenue and evidence for the product roadmap.

## Anti-drift rule

Backend migrations, new infrastructure, AI features and workspace tools may not silently redefine the product. If a technical change breaks the guided investigation, evidence reading, report, account trust, or R999 commercial path, the product regression takes priority over architectural expansion.
